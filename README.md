# Lumea Treats 🍓

A responsive website for **Lumea Treats**, a Lagos-based brand that makes fresh parfaits and creamy yoghurt daily, using quality fruits, granola and premium toppings. The brand was founded by Anyasodor Emmanuella.

## Features

- Responsive layout that works on phones, tablets and desktops
- Product showcase with prices in Naira
- Order buttons that open WhatsApp with the product name pre-filled
- Contact form that sends messages straight to the owner's inbox
- Customer reviews carousel

## Pages

| Page | File | What it has |
|------|------|-------------|
| Home | `index.html` | Banner carousel, about section, signature products with prices, services, customer reviews, contact form and newsletter |
| About | `about.html` | The story behind the brand |
| Menu | `icecream.html` | Full parfait and yoghurt menu |
| Services | `services.html` | What Lumea Treats offers |
| Blog | `blog.html` | Blog posts |
| Contact | `contact.html` | Contact details and message form |

## Running Locally

No build step is needed.

```bash
git clone https://github.com/eemmanuel-stack/Lumea-Treats.git
cd Lumea-Treats
```

Then open `index.html` in your browser, or serve it locally:

```bash
python -m http.server 8000
# visit http://localhost:8000
```
